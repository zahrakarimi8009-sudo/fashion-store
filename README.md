# فروشگاه نیلا — NILA FASHION

فروشگاه اینترنتی فارسی/راست‌چین زنانه — **بدون فریمورک**: HTML/CSS/JS خالص + APIهای PHP + دیتابیس MySQL.

> 📖 **راهنمای کامل و خوانا (معماری، نصب، بخش‌ها، رفع ایراد):** فایل [guide.html](guide.html) — در مرورگر باز کنید.

## نصب سریع (WAMP)

1. پوشه را در `D:\wamp64\www\fashion-store` کپی کنید.
2. در `http://localhost/phpmyadmin` → **Import** → فایل `nila_shop.sql` → Execute.
3. در صورت نیاز، `config/db.php` را ویرایش کنید (پیش‌فرض: `root` / رمز خالی / `nila_shop`).
4. باز کنید: `http://localhost/fashion-store`
5. سلامت‌سنجی: `http://localhost/fashion-store/diag.php` — ۷ چراغ سبز = همه‌چیز واقعی است.

## ساختار کلیدی

- **صفحه‌های اصلی:** `index.html`، `shop.html`، `product.html`، `cart.html`، `wishlist.html`، `checkout.html`
- **ورود/خروج مشتری:** `login.php`، `login_bridge.php`، `logout.php`
- **پنل کاربری:** `account.html` + `js/account.js`
- **پنل مدیریت:** `admin.php` (PHP واقعی؛ هنگام لود اتصال دیتابیس را سمت سرور چک می‌کند) + `js/admin.js`
- **APIها (JSON، سشن‌محور):** `api/products.php`، `api/reviews.php`، `api/orders.php`، `api/account.php`، `api/messages.php`، `api/notifications.php`، `api/admin.php` (۲۱ اکشن: ورود/داشبورد/سفارش/کاربر/مدیر/پیام/محصول با آپلود تصویر/تنظیمات)
- **تشخیص مشکل:** `diag.php` (۷ چراغ سلامت + راه‌حل فارسی هر خطا)
- **دیتابیس:** `nila_shop.sql` — ۱۱ جدول + داده‌های نمونه (۸ محصول، ۵ سفارش، ۱۰ نظر روی همه‌ی محصولات، ۳ مدیر)
- **اتصال/رمز:** `config/db.php` — PDO + `verify_password` (sha256+salt برای داده‌های نمونه، `password_hash` برای حساب‌های جدید)

## نکات طراحی

- اگر PHP/دیتابیس در دسترس نباشد، صفحات با **داده‌های نمایشی** کار می‌کنند (بدون خطا) و پنل مدیریت با نشانگر/بنر «حالت نمایشی» این موضوع را اعلام می‌کند.
- **برچسب «خریدار تأییدشده»** دینامیک است: مشتریِ لاگین‌شده‌ای که آن محصول در سفارش‌هایش باشد، هنگام ثبت نظر برچسب می‌گیرد (`reviews.user_id` + `orders` + `order_items`).
- **آپلود تصویر محصول:** JPEG/PNG/WEBP تا ۳MB در `api/admin.php` (اکشن‌های `product_add`/`product_update`) — فایل در `images/up-*.jpg` ذخیره و مسرش در دیتابیس می‌نشیند؛ هنگام حذف/جایگزینی، فایل‌های آپلودشده‌ی قدیمی پاک می‌شوند.
- **تغییرات پنل مدیریت** (افزودن/ویرایش/حذف/فعال‌سازی محصول) چون فروشگاه از `api/products.php` می‌خواند، **لحظه‌ای در صفحه‌ی اصلی اعمال** می‌شوند.
- کد تخفیف: `NILA10` (۱۰٪) — ارسال رایگان از ۲,۰۰۰,۰۰ تومان، وگرنه ۱۵,۰۰۰ تومان.
